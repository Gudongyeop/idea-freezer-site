재료를 모으고 섞어서 콘텐츠 만들기

매일 오늘의 질문에 한 줄 답하고, 메모·사진·링크를 냉장고에 넣어둬요. 필요할 때 재료 2~3개를 꺼내 레시피(릴스·썰툰·손그림…)와 섞으면 콘텐츠 아이디어가 돼요.

자주 묻는 것

기록은 어디에 저장되나요?
기본은 이 기기 안에만 있어요. 설정에서 Apple 로그인으로 기기 연동을 켜면 암호화된 채로 내 다른 기기와 오가요.

폰을 바꾸면요?
설정 → 백업 파일 만들기로 파일을 챙긴 뒤, 새 기기에서 설정 → 백업에서 되살리기를 눌러요.

잠금을 켰는데 열 수 없어요.
기기의 Face ID·지문·암호가 꺼져 있으면 잠금이 자동으로 풀려요. 기기 잠금을 다시 켠 뒤 앱 설정에서 잠금을 켜 주세요.

손글씨는 어디서 쓰나요?
iPad의 오늘 탭에서 '노트'를 열고 오른쪽 위 '손글씨'를 눌러요.
